# Brand marks

Files in this directory are third-party brand assets, kept exactly as distributed. They are not modified; the site controls only size and opacity, so every mark is shown in the color its owner distributes it in.

| File | Owner | Source | Fetched | Terms |
|---|---|---|---|---|

Forbidden: recoloring, reshaping, combining with text, use as one's own icon, implying affiliation. |
| `x-logo.svg` | X Corp. | X brand toolkit, https://about.x.com/en/who-we-are/brand-toolkit (`logo.svg`) | 2026-09-05 | Use the logo as provided, unaltered, per the toolkit's guidelines. |
| `zenn-mark-white.svg` | Classmethod, Inc. | Zenn media kit, https://zenn.dev/mediakit (`zenn-logo/logo-only-white.svg`) | 2026-09-05 | Permitted: mark alone; full color or monochrome; clear space of half the mark's size. Forbidden: distortion, added decoration, logotype alone, other colors. |
| `../images/kofi_symbol.png` | Ko-fi Labs Ltd. | Ko-fi brand assets, https://more.ko-fi.com/brand-assets | before 2026-09 | Use within the Ko-fi content guidelines. |
